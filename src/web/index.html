    Cómo funciona

    1. Crea una sesión indicando el directorio del proyecto.
    2. Escribe el objetivo. Antigravity planifica y reparte el trabajo.
    3. Los agentes se turnan: implementan, ejecutan pruebas y revisan.
    4. El ciclo termina cuando el arquitecto aprueba el resultado.
